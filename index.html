GPU Process Use-After-Free Vulnerability PoC

Warning: This demonstrates a critical security vulnerability in Chrome's GPU process architecture.

Vulnerability

// Vulnerable pattern in Chrome's GPU process: void CreateArcVideoDecodeAccelerator( ChromeContentGpuClient* client, viz::GpuServiceImpl* gpu_service) { // VULNERABILITY: Raw pointers captured into persistent callbacks auto callback = base::BindRepeating( &ArcVideoDecodeAccelerator::OnRequest, base::Unretained(client), // Raw pointer - no lifetime guarantee base::Unretained(gpu_service)); // Raw pointer - no lifetime guarantee // Callbacks stored in mojo::BinderMap persist for entire GPU process lifecycle gpu_service->binder_map().AddInterface( std::move(callback), base::ThreadTaskRunnerHandle::Get()); } // When client or gpu_service is destroyed, but callback remains: // 1. IPC request arrives // 2. Callback is invoked from binder_map // 3. Use-after-free occurs on destroyed object // 4. Memory corruption / potential code execution
